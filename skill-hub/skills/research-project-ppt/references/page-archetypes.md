# 页面原型

本文件回答"答辩/汇报中常见的某类页面，用什么构图与组织方式"。原型是常见页面类型与构图语法之间的映射：**构图**（见 [`composition-grammar.md`](composition-grammar.md)）定义抽象视觉结构，**原型**只补充该类页面的版面要点与内容组织规则。页面类型不匹配任何原型时，直接按构图语法选择，不要硬套。

通用前提（所有原型共享）：标题编号块 + 通栏细线；页首结论句；2–4 栏、栏宽与间距一致；底部结论带一句话（索引/陈述类页面除外）；页脚来源与页码。

## 1. 背景与需求

**适用**：为什么做、国家需求、行业痛点。
**构图**：证据场或双场（左文字/中证据/右图像）。

- 标题下先写一句判断，如"现有方法灵敏度不足，难以满足需求"。
- 分 2–3 栏：文字问题、数据证据、示意图或照片。
- 问题用红色短标签或红色加粗词；每个问题跟一句解释 + 一个证据（数字、图、照片）。
- 照片 ≤3 张，细边框 + 9–10 pt 图注。
- 结论带收束为需求导向的一句话。

**检查**：每个问题都有证据；没有三张以上照片堆叠。

## 2. 现状与差距

**适用**：卡脖子问题、研究现状、国内外对比。
**构图**：双场（左瓶颈列表 / 右对比表）。

- 左侧 2–3 个瓶颈：红色标题 + 灰底说明卡。
- 右侧表格：问题、现状、目标、差距；表头主蓝底白字，隔行浅蓝。
- 目标值红色加粗，现状值深灰，差距用红箭头或 ↑。
- 右侧可加一张机制或路线小图，不与表格抢空间。
- 结论带写"本页要解决的核心问题"。

**检查**：现状值与目标值一眼可区分；每行差距有量化表达。

## 3. 目标与指标

**适用**：目标设置、考核指标、预期成果。
**构图**：证据场 + 纵向标签分层。

- 左侧竖排色块标层级：战略目标 / 核心指标 / 技术指标（主蓝底白字，宽 0.9–1.2 in）。
- 每层一条横向流程：现状 → 目标 → 结果，节点用浅蓝卡片，箭头主蓝。
- 目标值 28–40 pt 红色加粗，单位 12–14 pt；同比幅度用绿/红小标签。
- 三层之间向下箭头连接，保持同一条左边界。
- 结论带写"目标是否可考核"的判断，或省略让表格说话。

**检查**：每个目标可量化、可考核；层级不超过三层。

## 4. 技术路线

**适用**：技术路线、研究方案、实施路径。
**构图**：序列轨（3–5 阶段横向）。

- 每阶段一张卡片：阶段名、关键动作、输出物；阶段内 2–3 行短句。
- 阶段间主蓝箭头；回流迭代用虚线箭头。
- 里程碑/卡点用橙色或红色小标签。
- 下方可加时间轴或年度标记（10–12 pt）。
- 只讲一条主线；分支放下一层页面。

**检查**：每阶段有输出物；没有超过 5 个阶段。

## 5. 机制与原理

**适用**：作用机制、技术原理、材料结构。
**构图**：星座场或序列轨（2–3 个面板从左到右讲因果）。

- 每个面板一个浅蓝标题条；同一实体同一颜色（材料、分子、设备各一套固定画法）。
- 阶段或环境用区域底色分组（≤3 区），区与区之间留白分隔，不用箭头围边。
- 促进用实线箭头，抑制用平头线；反馈、可选路径用虚线，含义写进图注。
- 面板内文字 2–4 行；关键术语蓝色加粗，关键数字红色。
- 示意图用扁平几何或统一风格；不混用 3D 图标、写实渲染与线稿。
- 结论带写"机制说明了什么"，不重复图注。

**检查**：实体配色一致；箭头语义有图注。

## 6. 结果

**适用**：关键指标、性能对比、实验结果。
**构图**：焦点场（主图 + 数字）。

- 主图（折线/柱状/照片/显微图）占 50–65%；一页只放一张主图，多图拆页或 A/B 双面板。
- 侧栏 2–3 个关键数字：28–40 pt，红或主蓝；下一行小字说明单位与对比对象。
- 图注写 n、误差线、统计方法；数据来源放页脚。
- 达标用绿标签，未达标/差距用红标签；不用红绿同时表达同一含义。

**检查**：数字有单位、有来源、有对比对象。

## 7. 团队

**适用**：负责人、研究团队、人员构成。
**构图**：星座场（3–4 栏成员卡）或焦点场（负责人占两栏 + 团队）。

- 每栏：照片、姓名、职称、1–2 行经历、1 行分工。
- 照片统一尺寸、统一背景、细边框；不拉伸。
- 负责人可占两栏，列 3–5 条代表性成果。
- 不放大段简历；详细简历放附件。
- 团队结构用一句话放结论带。

**检查**：照片规格一致；每人有一行分工。

## 8. 平台与条件

**适用**：研究基础、实验平台、条件保障。
**构图**：双场（左照片组 / 右能力表）。

- 左侧设备/平台照片 2–4 张，统一比例、细边框、9–10 pt 图注（设备名 + 用途）。
- 右侧能力表格：平台/设备、能力、归属；表头蓝底，正文 10–12 pt。
- 政策/资金支持用浅蓝提示条或小卡片，不用大红大绿。
- 结论带写"这些条件如何支撑目标"。

**检查**：照片有图注；能力与目标有对应关系。

## 9. 成果与预期成果

**适用**：前期基础、承担项目、获奖、预期成果。
**构图**：证据场（表格）+ 目录场（证书/网格）。

- 项目/论文/专利用三线表或蓝头表格；数量、等级、状态分列。
- 状态标签："已完成"绿、"在研"蓝、"待启动"灰；不整行变色。
- 证书/奖牌/论文首页 2–4 张缩略图，统一高度，细边框，不铺满。
- 预期成果用 2×3 或 3×2 网格：标题 + 2–3 行说明 + 1 个量化指标。
- 结论带写"成果的不可替代性"或"预期影响"。

**检查**：每格预期成果有量化指标；缩略图不拉伸。

## 10. 总结

**适用**：总结页。
**构图**：星座场（≤3 列，每列一个结论）。

- 3 列以内，每列一个结论；或 3 条横排卡片。
- 不引入新数据、新图表。
- 结论措辞与页首结论句、结论带呼应，不重复正文原句。

**检查**：没有新信息；每列一句话。

## 原型 → 构图速查

| 原型 | 首选构图 | 备选 |
|---|---|---|
| 背景与需求 | 证据场 / 双场 | 焦点场 |
| 现状与差距 | 双场 | 证据场 |
| 目标与指标 | 证据场 + 纵向标签 | 序列轨 |
| 技术路线 | 序列轨 | 星座场 |
| 机制与原理 | 星座场 / 序列轨 | 证据场 |
| 结果 | 焦点场 | 证据场 |
| 团队 | 星座场 | 焦点场 |
| 平台与条件 | 双场 | 目录场 |
| 成果与预期 | 证据场 + 目录场 | 星座场 |
| 总结 | 星座场 | 陈述场 |

同一原型连续出现时必须换构图（如两页"现状与差距"：第一页双场，第二页证据场）。
