# 科研学术演示的美学系统

本文件定义"学术蓝 · 理性秩序"的可量化标准。它不规定页面写什么内容、分几个章节；它规定任何内容进入画面后必须满足的视觉量。单位以英寸（in）与磅（pt）为权威，同时给出 96dpi 下的 px 换算（画布 13.333×7.5 in = 1280×720 px，1 in = 96 px，1 pt ≈ 1.333 px）。

适用：项目申报、中期检查、结题答辩、科技奖答辩、实验室/团队汇报等高密度评审型演示。
不适用：学术会议报告。会议报告一页一个观点、正文 18–24 pt，属于稀疏版式，不使用本系统的密度档。

## 0. 美学命题

- 关键词：冷静、秩序、密度、可信。
- 视觉温度：冷色，主色相 215–225°；背景高明度，主体低明度；饱和度克制。
- 两个层次：深色"陈述页"（封面、章节、结束）与浅色"证据页"（正文）。深色页占比 15–25%，负责定调；浅色页负责承载信息。
- 每页只允许一个视觉重心。第二重心必须弱于第一重心至少 30%（面积或对比度）。
- 每页有一句"页首结论"：标题之下先给判断或问题，读者不看正文也知道这页要说什么。
- 风格不靠装饰成立，靠比例、对齐、字阶和留白成立。去掉所有装饰线后，页面仍应成立。
- 分组靠区域底色与留白，不靠色块堆叠；颜色按逻辑分组，不按装饰轮换。

### 区域底色（分组）

区域底色是"逻辑容器"，不是装饰色块。用于圈定阶段、环境、候选范围，让读者先看到分组，再看到细节。

| 色调 | 底色 | 边框 | 语义 |
|---|---|---|---|
| 冰蓝 | `#F2F8FE` | `#D7E7F7` | 技术阶段、系统内部、主流程 |
| 雾白 | `#F5F7FA` | `#E2E8EF` | 中性分组、并列模块 |
| 米色 | `#FBF7EC` | `#EAE0C8` | 外部条件、输入、环境 |
| 淡紫 | `#F5F1FA` | `#E3DAF0` | 候选方案、对照实验 |

- 同一语义全 deck 同色；全 deck 区域色调 ≤2 种，推荐"冰蓝 + 雾白"。
- 同页 ≤3 区；单区着色面积 ≤25% 页面面积，全页区域底色合计 ≤45%。
- 区域用 0.75 pt 虚线边框，表示"逻辑范围"；区内仍用白底卡片，不叠加第二层底色。
- 区域底色与页面背景明度差 ≤6；禁止高饱和底色、渐变底色、阴影容器。
- 米色、淡紫只在确有"外部/候选"语义时使用，不按页面轮换。

### 语义规则（本系统的核心约束）

- 蓝色负责**结构**；红色负责**目标与差距**；绿色负责**已完成与达标**；橙色只做**提醒**。
- 红色只标"目标、差距、风险、关键数字"，禁止整段红字、禁止做大面积填充（单块 ≤40×40 px）。
- 绿色只标"已完成、达标、提升"，禁止当装饰。
- 同一页的强调色不超过两种；红、金不同时出现在同一页；红只在浅底，金只在深底。
- 红色文字每页 ≤3 处，面积 ≤正文的 2%；目标值必须与现状值一眼可区分（红加粗 vs 深灰）。
- 正文不用纯黑，用 `#1F2937`；浅灰只用于注释和页脚。

### 配比与对比

| 层级 | 面积占比 |
|---|---|
| 中性场（白/极浅蓝） | 60–75% |
| 主蓝族 | 20–35% |
| 语义强调（红绿橙合计） | 2–5%，超 5% 即失败 |

- 渐变只允许两类：深色陈述页背景、卡片头/标题条；≤2 色标、色相差 ≤15°、明度差 ≤18。
- 正文对比 ≥7:1，次要文字 ≥4.5:1；红色/金色文字按 4.5:1 检查。
- 禁止阴影、发光、玻璃拟态、3D、纹理贴图、水印、模板店标识、无关 logo。

## 3. 字体与字阶

- 字体家族 ≤2：中文全用无衬线（微软雅黑/思源黑体）；封面可按奖项风格换宋体（方正小标宋/思源宋体）；一页不超过两种字族。
- 字重 ≤2：400 与 700；中文不用斜体；英文不全大写；数字加粗且同族。
- 字体分工固定：模块名、流程标签、正文用无衬线；变量、符号、公式用衬线斜体（Times / 思源宋体）；中文不使用斜体，也不做伪斜体。

| 角色 | 字号（pt） | px | 字重 |
|---|---|---|---|
| 封面主标题（奖答辩） | 40–54 | 53–72 | 700，宋体 |
| 封面主标题（项目答辩） | 36–44 | 48–59 | 700 |
| 封面副标题 | 22–26 | 29–35 | 700 |
| 页面标题 | 24–28 | 32–37 | 700，≤20 汉字 |
| 标题编号块 | 18–20 | 24–27 | 700，白 |
| 页首结论句 | 16–18 | 21–24 | 700 |
| 卡片头/小节标题 | 15–17 | 20–23 | 700，白 |
| 正文 | 14–16 | 19–21 | 400 |
| 表格 | 10–12 | 13–16 | 400 |
| 图注/来源 | 9–10 | 12–13 | 400 |
| 页脚/页码 | 9 | 12 | 400 |

- **数字层级**：关键数字比正文大 2–4 级，目标值 28–40 pt 红色加粗，单位 12–14 pt 灰色。
- 两档密度（同一 deck 不得混用）：
  - **投影汇报档**（现场答辩）：正文 ≥14 pt，表格 ≥10 pt；违反就拆页或删字。
  - **高密度审阅档**（屏幕送审，参考实现默认）：正文 ≥12 px，表格 ≥11 px。
- 中文正文行长 18–34 字；文本块 ≤3 行；标题 20 汉字以内。
- 页面标题写"主题"，下一行紧跟"结论/问题"，不要只放标题就进入内容。

## 4. 固定元素

- **标题编号块**：0.62×0.45 in（60×43 px）圆角矩形，主蓝底、白色编号（1.1、2.3），左侧距边距；编号与标题同基线。
- **标题分隔线**：左边距通到右边距，主蓝 0.75 pt；左端可加 2 pt 深蓝短线。
- **页首结论句**：标题下 1–2 行加粗，点明"问题/结论/目标"，不写套话。
- **卡片**：白底、`#C9D8EA` 0.75 pt 边框、浅蓝卡片头（主蓝底白字，高 0.4–0.45 in）；内边距 0.12–0.18 in；圆角 0.04–0.08 in 全 deck 统一；内部不再套多层框。
- **底部结论带**：整幅宽（左右到边距），主蓝底、白字 14–16 pt，一句话总结本页；结论带只有一句话。
- **页脚**：左侧来源/备注，右侧页码，9 pt，`#909090`；照片/证书有 9–10 pt 图注。

## 5. 密度与留白

| 密度档 | 墨迹覆盖 | 适用 |
|---|---|---|
| 呼吸 | 45–55% | 章节页、单点结论、关键指标 |
| 标准 | 55–70% | 大多数证据页 |
| 密集 | 70–80% | 表格、矩阵、系统图 |

- 单页墨迹覆盖 ≤80%；留白 ≥25%。
- 证据页 2–4 个主模块；陈述/索引/目录型页可为 1 个主构图；每模块要点 ≤6；层级 ≤2 级。
- 页面不得整页纯文字；纯文字页只允许目录、章节页、结束页。
- 连续 2–3 个密集页后插一个呼吸页；同一构图连续 ≤2 页。

墨迹覆盖 =（文本 ∪ 图像 ∪ 表格/卡片填充区）/ 内容区面积，不含页面背景。

## 6. 视觉重量与构图

- 主模块 55–70%，支撑模块 25–35%，强调 5–10%。
- 最大模块 ≥ 第二模块的 1.5 倍；并列构图允许等重，但只能有一个强调焦点。
- 阅读路径从左上开始，Z 形或 F 形；两个对角不得同时争夺焦点。
- 对称只用于"对照"；非对照页用非对称平衡。
- 深色陈述页负空间 ≥45%。
- 具体结构按 [`composition-grammar.md`](composition-grammar.md) 的 8 种抽象构图选择；常见页面类型到构图的映射见 [`page-archetypes.md`](page-archetypes.md)。

## 7. 形状、线、装饰

- 边框 0.75 / 1 / 1.5 pt（1–2 px）；圆角 0.04–0.08 in 全 deck 统一。
- 线只做三种用途：标题分隔、表格网格、流程连接。
- 装饰母题 ≤2 类，面积 ≤10%，与背景明度差 ≤8%；封面可加极淡几何线条/同心圆。
- 箭头只表示方向，单页 ≤5 个；实线促进、平头抑制，含义写进图注。
- 禁止图标库堆砌、剪贴画、emoji、3D 图标、写实渲染与线稿混用。

### 线语义

| 线型 | 含义 | 用法 |
|---|---|---|
| 实线 1–1.5 pt | 主流程、数据流、因果 | 主路径只允许一条 |
| 虚线 0.75–1 pt | 辅助流、可选路径、反馈、逻辑范围 | 必须有标签或图注说明 |
| 平头线 | 抑制、阻断、冻结 | 与实线箭头成对出现时须注明 |
| 正交折线 | 结构、矩阵、层级 | 用于架构与流程分叉 |
| 曲线 | 反馈、高层数据流 | 不与正交折线表达同一含义 |

- 同一含义只用一种线型；虚线不得围边装饰，箭头不得做项目符号或分隔符。
- 箭头粗细不超过所在容器边框的 2 倍，避免箭头比内容醒目。

### 形状语义

| 形状 | 语义 | 约束 |
|---|---|---|
| 圆角矩形（3–6 px） | 流程、模块、步骤 | 默认形状，占流程节点 ≥80% |
| 直角矩形 | 数据、张量、矩阵、表格单元 | 与圆角流程节点区分 |
| 仓储形 | 数据库、缓存、平台底座 | ≤2 个/页，不与直角块混用 |
| 虚线容器 | 逻辑阶段、可选范围 | 同页 ≤3 个，即区域底色 |

- 同一实体全 deck 同形同色；颜色区分状态（在研/完成/冻结），不区分装饰类别。
- 本系统默认 2D；2D 与 3D 不混用，流程图不用立体块。
- 宏微观：大容器表示整体，引出一条线连接局部放大框；放大框只连一条线，避免交叉。

## 8. 图像

| 指标 | 约束 |
|---|---|
| 数量 | 证据页 1–3 张；并列主体/目录型 ≤6 张；不超过 3 张照片堆叠 |
| 面积 | 证据图占内容区 20–40%（结果页主图 50–65%） |
| 比例 | 同页图片比例一致；照片统一尺寸统一背景 |
| 边框 | 1 px `#C9D8EA`，圆角 ≤3；不拉伸、不压字、不加遮罩 |
| 图注 | 9–10 pt，写清内容、设备名称或用途；数据来源放页脚 |
| 裁切 | 照片 cover；截图/图表 contain，四周留白 ≥4% |

- 一页只放一张主图；需要多图时拆页或 A/B 双面板。
- 图文比只允许 40:60 或 60:40，避免 50:50 暧昧分割。

## 9. 表格与数据图形

- 表格通栏或 55–100% 宽；表头主蓝底白字（或浅蓝底深蓝字，全 deck 二选一）；隔行浅蓝。
- 表内字号 10–12 pt；数字右对齐或居中；单位写在表头或单元格内；小数 ≤1 位。
- 对比表列序固定：问题/对象 → 现状 → 目标 → 差距；目标值红加粗，现状深灰，差距用红箭头或 ↑。
- 状态用标签："已完成"绿、"在研"蓝、"待启动"灰；不要整行变色。
- 图表颜色 ≤3；网格线对比 ≤20%；数据墨水比 ≥70%；饼图 ≤4 片；不用 3D、阴影、渐变填充。

## 10. 跨页节奏

- 深色陈述页占 15–25%（浅色封面家族 5–25%）；不连续两页深色（封面→章节除外）。
- 密度节奏：密集 → 标准 → 呼吸循环；连续三页同密度即失败。
- 页眉、编号块、卡片、页脚位置全套一致；只允许一种封面家族。
- 章节页与目录页同构（左侧竖版），只切换高亮项。
- 评审时间短时：背景与现状合并、团队与平台合并，但目录仍保留约四项。

## 12. 失败模式

- **模板感**：每页三张等宽卡片；所有页同一构图；编号块/页脚位置漂移。
- **装饰依赖**：靠阴影、渐变、图标、光晕成立；去掉装饰页面散架。
- **语义色失控**：红绿橙当装饰；整段红字；绿色铺卡片；同页强调色超过两种。
- **密度失控**：整页文字墙；为塞内容把正文降到下限以下；一页 6 个以上模块。
- **层级失控**：标题、卡片头、正文、注释字号接近；三级缩进；数字没有放大层级。
- **对齐失控**：栏宽不一、左边界 4 种以上、图片表格不落栏线。
- **区域滥用**：每页几块彩色底；底色过饱和；区域不表达分组，只做装饰轮换。
- **语义混乱**：同一含义混用实线虚线；虚线围边；流程用直角、数据用圆角；2D 与 3D 混搭。
- **字体混用**：标签用衬线、变量用无衬线、中文倾斜；同页三族以上。
- **图像失控**：拉伸、压字、collage、比例混杂、无图注、无来源。
- **数据失控**：3D 图表、饼图切片过多、网格线比数据重、目标值与现状值分不清。
- **结论缺失**：只有标题没有页首结论句；结论带写了废话或超过一句话。
- **内容错位**：把版式当内容脚本，强行规定"必须写谁、必须分几章"。
- **场合错位**：把这套高密度系统用于学术会议报告；会议报告应使用稀疏版式。
